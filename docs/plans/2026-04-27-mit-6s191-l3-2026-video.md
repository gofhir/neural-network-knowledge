**Step 3: Verify no PNG exceeds 2000px on long side**

Run:
```bash
for f in site/static/videos/mit-6s191-l3-2026/slides/*.png; do
  identify -format "%f %wx%h\n" "$f"
done | awk '{split($2,d,"x"); m=d[1]>d[2]?d[1]:d[2]; if(m>2000) print "OVERSIZE:", $0}'
```

Expected: no output (no oversize). If any OVERSIZE printed, retry Step 1 with `-r 144` (or lower) and re-verify.

**Step 4: Normalize filenames to zero-padded `slide-NN.png`**

`pdftoppm` outputs `slide-1.png`, `slide-10.png`, etc. — un-padded. Normalize so lexicographic order matches numeric order.

Run:
```bash
cd site/static/videos/mit-6s191-l3-2026/slides
total=$(ls *.png | wc -l | tr -d ' ')
width=${#total}
for f in slide-*.png; do
  num=$(echo "$f" | sed -E 's/slide-([0-9]+)\.png/\1/')
  padded=$(printf "%0${width}d" "$num")
  newname="slide-${padded}.png"
  if [ "$f" != "$newname" ]; then
    mv "$f" "$newname"
  fi
done
ls | head -5
ls | tail -5
cd -
```

Expected: filenames padded (e.g., `slide-01.png` to `slide-83.png` for an 83-page deck).
