## 3. Pipeline de imágenes

**Conversión PDF → PNG con `pdftoppm` (poppler):**

```bash
# 1. Verificar / instalar poppler
which pdftoppm || brew install poppler

# 2. Descargar PDF
curl -L -o site/static/videos/mit-6s191-l3-2026/slides.pdf \
  https://introtodeeplearning.com/slides/6S191_MIT_DeepLearning_L3.pdf

# 3. Renderizar a PNG con DPI 150 (16:9 a 13.33"x7.5" → ancho ≈ 2000px)
mkdir -p site/static/videos/mit-6s191-l3-2026/slides
pdftoppm -png -r 150 \
  site/static/videos/mit-6s191-l3-2026/slides.pdf \
  site/static/videos/mit-6s191-l3-2026/slides/slide

# 4. Verificar que ningún PNG exceda 2000px en su lado largo
for f in site/static/videos/mit-6s191-l3-2026/slides/*.png; do
  identify -format "%f %wx%h\n" "$f"
done | awk '{split($2,d,"x"); m=d[1]>d[2]?d[1]:d[2]; if(m>2000) print "OVERSIZE:", $0}'
```

**Plan B si OVERSIZE:** reducir `-r` a 144 o menos y re-renderizar. PNG (no JPG) para preservar texto y bordes nítidos.

**Renombrado:** `pdftoppm` genera `slide-1.png`, `slide-12.png`, etc. (sin zero-padding). Tras renderizar, normalizar a `slide-01.png`, `slide-02.png`, ... con un loop `mv` para orden lexicográfico estable.

**Tamaño esperado:** ~250-400 KB × ~80 slides ≈ 20-30 MB en `static/`. Aceptable para Hugo.

## 4. Ejecución secuencial

Sin subagentes. El agente principal hace todo en este orden:

1. **Setup** (Task 1 del plan): crear directorios, descargar PDF, renderizar PNGs, verificar tamaños, normalizar nombres.
2. **Inspección inicial** (Task 2): leer slide 1 (portada/agenda) y muestreo de slides distribuidas (10, 20, 40, 60, última) para confirmar la división temática real del lecture y el conteo de páginas. Ajustar la división de bloques si los temas no calzan con la estimación inicial.
3. **Redacción de `notas.md`** (Tasks 3a/3b/3c): tres bloques temáticos consecutivos. Cada bloque:
   - lee 10-15 PNGs de su rango con la herramienta `Read`,
   - escribe la sección correspondiente directamente en `notas.md`,
   - embebe slides clave inline (`![slide N](/videos/mit-6s191-l3-2026/slides/slide-NN.png)`),
   - cita refs como `*(slide N)*`.

   División temática estimada (a confirmar tras inspección):
   - **Bloque I:** motivación, percepción humana vs. máquina, representación de imágenes (píxeles, channels), limitaciones de fully-connected, convolución (kernel, stride, padding), feature maps.
   - **Bloque II:** pooling, jerarquía de features, arquitecturas clásicas (LeNet → AlexNet → VGG → Inception → ResNet), batch normalization, regularización, data augmentation.
   - **Bloque III:** aplicaciones — clasificación, detección (R-CNN family, YOLO), segmentación (FCN, U-Net), generación (GANs/difusión si aparece), interpretabilidad, transfer learning, cierre.

4. **Redacción de `profundizacion.md`** (Task 4): leer `clases/clase-09/profundizacion.md` y `fundamentos/redes-convolucionales.md` para no duplicar; escribir investigación complementaria con papers seminales (LeCun 1998, Krizhevsky 2012, Simonyan 2014, Szegedy 2015, He 2015, Ioffe 2015, Girshick 2014, Redmon 2016, Long 2015, Ronneberger 2015, Selvaraju 2017), comparación con clase-09, y conceptos no cubiertos por MIT (Vision Transformers, ConvNeXt, EfficientNet, autoencoders convolucionales).
5. **Redacción de `glosario.md`** (Task 5): 30-45 términos bilingües, agrupados por bloque temático (convolución básica, arquitecturas, aplicaciones, interpretabilidad).
6. **`_index.md` y cross-links** (Task 6): embed YouTube, cards a las subpáginas, ver-también, atribución MIT. Updates en los `_index.md` pares.
7. **Build y commit** (Task 7): `hugo --gc --minify`, fix errores si los hay, commit sin Co-Authored-By.

**Manejo del contexto:** los PNGs son visuales (token-pesados). Lectura por lotes pequeños (10-15 slides por turno), escritura inmediata a `notas.md`, no acumular múltiples bloques de imágenes en contexto.

## 6. Riesgos y mitigaciones

| Riesgo | Mitigación |
| --- | --- |
| `pdftoppm` no instalado | `brew install poppler` antes de Task 1, falla rápido si no hay brew |
| PNGs > 2000px | Verificación post-render con `identify`; reducir `-r` y re-renderizar |
| División temática estimada no calza con el lecture real | Task 2 (inspección) ajusta los rangos antes de redactar |
| Contexto saturado por imágenes | Lotes de 10-15 slides, escritura inmediata, descartar imágenes ya procesadas |
| Tamaño total de PNGs en repo (~20-30 MB) | Aceptable para Hugo; alternativa si crece: gitignore + servir desde CDN (no aplica ahora) |
| Duplicación con `clase-09/profundizacion.md` | Lectura previa obligatoria en Task 4; cross-link en vez de re-derivar |
