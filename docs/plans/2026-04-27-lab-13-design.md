## Sección 2 — Contenido de cada página Hugo

### `_index.md` (~2-3 KB)

Frontmatter + 4 secciones:
1. Encuadre del lab: 3 partes (sin attention → con attention → teacher forcing), prof Gabriel Sepúlveda, fecha.
2. Cross-link a la teoría de la clase: card a `/clases/clase-13/`.
3. Cards de navegación: `seq2seq-basico`, `seq2seq-attention`, `teacher-forcing`, `ejercicios`, `resolucion`.
4. Cards de descarga: 3 notebooks RAE (.ipynb) y 3 renders HTML.

### `seq2seq-basico.md` (~8-12 KB) — parte 1

Cubre lo que hace y aprende el notebook 1:
- Setup del problema (translation, par de idiomas a confirmar al ejecutar parte 1).
- Arquitectura encoder-decoder: clase Encoder, clase Decoder, dimensiones, hidden state como context vector.
- Loop de entrenamiento: train utils, loss (probable cross-entropy), optimizador.
- Resultados modelo base: curvas loss + ejemplos de traducción (placeholders hasta tener outputs reales).
- Limitación a evidenciar: calidad de traducción degrada con secuencias largas (motivación para attention).

### `seq2seq-attention.md` (~10-14 KB) — parte 2

- Por qué attention: recap del bottleneck del seq2seq básico.
- Attention Module: código del módulo, fórmula del score (Bahdanau additive), softmax sobre encoder hidden states, context vector adaptativo.
- Decoder con attention: cómo cambia el decoder respecto a parte 1.
- Resultados con attention: curvas + comparativa contra parte 1 (calidad de traducciones, BLEU si lo calcula el notebook).
- Visualización del attention map: la sección "visualize attentions" del notebook 2 — heatmap de atención sobre tokens fuente al generar cada token destino. Sección estrella didácticamente.

### `teacher-forcing.md` (~6-9 KB) — parte 3

- Qué es teacher forcing: durante training, usar el ground-truth del paso anterior como input al decoder en lugar del output predicho.
- Por qué se usa: convergencia más rápida, evita compounding de errores tempranos.
- El problema (exposure bias): desalineación train/inference porque en inference no hay ground truth disponible.
- Implementación en el notebook: cómo se aplica el teacher forcing ratio.
- Resultados comparativos: entrenamiento con vs sin teacher forcing.

### `ejercicios.md` (~3-5 KB)

Enunciados de las Actividades 1.1 y 1.2 del notebook 3 (transcribir literalmente desde las celdas markdown del notebook). Si hay otras tareas implícitas (interpretar attention map, comparar variantes), enumerarlas. SIN respuestas.

### `resolucion.md` (~10-15 KB)

- Actividad 1.1: respuesta razonada con código + outputs.
- Actividad 1.2: respuesta razonada con código + outputs.
- Insights consolidados de las 3 partes: qué aprendió el alumno (bottleneck → solución attention → estabilización con teacher forcing → ejercicios prácticos).
